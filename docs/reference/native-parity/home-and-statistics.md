# Native parity inventory: Home, Statistics and reports

> [!abstract] Scope
> Routes: `/`, `/statistics`. Source: `apps/frontend/src/pages/DashboardPage.tsx`, `apps/frontend/src/pages/StatisticsPage.tsx`, `apps/frontend/src/features/dashboard/`, `apps/frontend/src/features/statistics/`, `apps/frontend/src/features/reports/`, `apps/frontend/src/components/charts/`. Part of [[docs/reference/native-parity/index|the native parity inventory]] for [[docs/adr/204-vision-native-swift-app-target|ADR-204]].

Labels are the English strings from `i18n/source/en.json` for the key the code uses. Plural keys
(`tc(...)`) are given with their `.one` / `.other` text. Charts shared by both screens are described
once under [[#Cross-cutting notes]] ("Chart primitives") and referenced from the rows.

## Screens

### `/` — Home

Component: `apps/frontend/src/pages/DashboardPage.tsx`. Feature docs: [[docs/adr/181-home-transactions-redesign|ADR-181]], [[docs/features/cash-flow-forecast|Cash flow forecast]], [[docs/features/net-worth|Net worth]].

**Native implementation (phase 3g part A).** `/` now uses `HomeView` and `HomeModel`.
`InsightTimelineChart` supplies hover, drag comparisons, keyboard navigation, and the shared
balance/forecast selection. `HomeCategoryChart` keeps category drill links and the top-five,
Uncategorised, and Other groups. `HomeForecastDiagnostics` shows backtests, persisted accuracy,
and ensemble-weight previews. Add transaction reuses `TransactionAddSheet`; after creation it
navigates to the native inspector. Widget choices use `widget_visibility` with compare-and-swap,
and inactivity/upcoming dismissals use the web app's existing local-storage keys.

The `native` rows below identify implemented controls. A macOS app build and the owner's visual
pass on Vision Native Demo are still required before this screen meets ADR-204's exit gate.
The cloud verification runs the portable model/adapter tests; it does not exercise SwiftUI,
AppKit, WebKit, or real runtime services. Insights and its phase-3p shared report sheet now render
natively. `NativeReportModel` owns report forms and serialization through the existing PDF APIs;
its tax context still delegates fiscal computation to shared TypeScript. macOS save-panel,
keyboard/accessibility and rendered PDF verification remain pending.

**Phase 3p continuation.** `export=pdf` opens `NativeReportSheet` through the shared shell overlay.
`NativeReportModel` retains a same-page draft, preserves the source period/sections/currency and
exclusion inputs, uses the server's fiscal figures, and prints the `ReportDocument` the report routes now answer
(ADR-234; `NativeReportsAPIService` hands its HTML to `NativeReportHTMLPrinter`) to the PDF it saves. Closing removes only `export` with replace, retaining the native tab/window. The report

separate workflow: `NativeStatisticsPrintSnapshot` freezes the currently loaded tab, filters,

section views and measured pivot, payee and yearly-summary table rows without new queries. Table

printable width; optional totals/notes print once as a footer, kept with the last row when they fit.
Rows that fit below a fresh header stay whole. Oversized single rows/footers and a header consuming
the paper height retain the explicit fallback limits in [[docs/architecture/native-app|native architecture]].

certify runtime, keyboard, accessibility, rendered output or physical printer parity.

## Cross-cutting notes

- **Chart primitives** (`apps/frontend/src/components/charts/`): `BarChart`, `StackedBarChart`, `LineChart`, `AreaChart`, `DonutChart`, `Sparkline`, `ChartLegend`. All cartesian charts show a tooltip on hover and are focusable with the keyboard map above (`CartesianChartFrame.tsx:131-132`, `BarChart.tsx:420-457`, `StackedBarChart.tsx:311-312`). `LineChart` and `AreaChart` with `scrubbable` support pointer-drag range compare with a Δ readout (`scrub.tsx:14-59`, `LineChart.tsx:288-294,579-636`, `AreaChart.tsx:376-382,669-726`). `syncId` charts share the hovered x through `ChartSyncProvider`, which wraps the whole Home page (`ChartSyncContext.tsx:18-40`, `DashboardPage.tsx:558`); on Home that is the balance history and the forecast (`"dashboard-timeline"`). `ChartLegend` is display-only (no legend toggles). `DonutChart` slices become links when the datum has `to` (Home only). `ChartPeriodSelector`, `ResearchRangeSelector` and `CandlestickChart` are not used on these two screens.
- **Exclusion toggle** (`apps/frontend/src/components/shared/ExclusionToggle.tsx:18-61`): outline button `exclusion.filtersActive` "Exclusions on" / `exclusion.filtersIgnored` "Exclusions off", `aria-pressed`, tooltip `exclusion.tooltipActive` / `exclusion.tooltipInactive`. Hidden entirely when Settings has no exclusions for the page scope. State is per graph key and per page visit (React state, not persisted, not in the URL). Home keys: `monthlyTrends`, `categoryPie`, `recentTransactions`. Insights keys: `monthly`, `netTrend`, `categoryPie`, `categoryTrend`, `pivotTable`, `topRecipients`, `yearlyComparison`, `sankey`.
