# Native parity inventory: Research and AI chat

> [!abstract] Scope
> Routes: `/research`, `/research/markets`, `/research/market`, `/research/watchlist`, `/research/compare`, `/research/forecast`, `/research/charts`, `/research/dossiers`, `/ai-chat`. Source: `apps/frontend/src/pages/research/`, `apps/frontend/src/pages/AIChatPage.tsx`, `apps/frontend/src/features/research/`, `apps/frontend/src/features/ai-chat/`, `apps/frontend/src/components/shared/SymbolSearchBox.tsx`, `apps/frontend/src/components/shared/SymbolSearchResultItem.tsx`, `apps/frontend/src/components/shared/RemoteNewsImage.tsx`. Part of [[docs/reference/native-parity/index|the native parity inventory]] for [[docs/adr/204-vision-native-swift-app-target|ADR-204]].
>
> Also walked because these screens render them: `apps/frontend/src/features/portfolio/AddToWatchlistDialog.tsx`, `apps/frontend/src/features/portfolio/WatchlistChartDialog.tsx`, `apps/frontend/src/features/portfolio/AddInvestmentFromMarketDialog.tsx` (summarized; its transaction form fields belong to the Portfolio inventory), `apps/frontend/src/features/portfolio/PortfolioNewsFeed.tsx`, `apps/frontend/src/components/charts/ResearchRangeSelector.tsx`. `/research/dossiers` is included because it is a Research route in `apps/frontend/src/lib/routePreload.ts:196` and the Research sidebar section (`apps/frontend/src/lib/navigation.ts:235`).
>
> Out of scope: the global command palette (its cashtag result links to `/research/market?symbol=`, `apps/frontend/src/components/shared/CommandPalette.tsx:215`), the sidebar, and the Settings AI section. Those belong to the shell and Settings inventories.

Feature docs: [[docs/features/research|Research]], [[docs/features/research-dossiers|Research Dossiers]], [[docs/features/watchlist|Watchlist]], [[docs/features/market-lookup|Market Lookup]], [[docs/features/ai-chat|AI Chat]].

**Native implementation (phases 3l–3n):** Research home, Markets, Market lookup, Watchlist and Compare
are implemented by `ResearchScreens` and the five native views under `apps/native/`. Provider/cache
metadata, nulls and exact numeric values remain attached to their responses. Financial/statistical
presentation stays in shared TypeScript behind the submitted-data API; native chart geometry alone
uses floating point. The wrapper owns route visits/connectivity and the existing portfolio-form
leave guard; child screens own polling. Phase 3m adds `ResearchForecastScreens`/Forecast and Life
views plus `ResearchChartBuilderModel`/Chart Builder views, with the existing scenario settings CAS
and shared v2 layout storage. Provider data and financial/chart preparation remain TypeScript-owned.
Phase 3n adds Dossiers and AI chat/Investigation. All 222 action rows now have native controls;
Dossiers keeps immutable version CAS/evidence/exports, Chat streams survive navigation, and
TypeScript supplies tool presentation without changing raw results or model context.
Native status records implemented controls, with macOS build, EN/NL rendering, focus, VoiceOver and
synthetic Demo parity checks still pending. See [[docs/architecture/native-app|Native architecture]].

#### Dialog: Add to watchlist (`AddToWatchlistDialog`, prefilled)

Opened from: row 2 above (prefill path), and from the Watchlist screen (search path). Source: `apps/frontend/src/features/portfolio/AddToWatchlistDialog.tsx`. Title and description `addWatchlist.title` "Add to watchlist" (`:206`). The body is a real form; Enter submits in the details step and is a no-op in the search step (`:135`).

> [!note] Native implementation and verification
> `ResearchWatchlistAddSheet.swift` and `ResearchWatchlistAddModel.swift` implement both search and prefilled paths. The selected-symbol quote supplies the immutable `added_price` snapshot; unavailable quotes omit it. Target preview arithmetic stays in the TypeScript presentation bridge. Change retains entered fields; dismissal clears the selected asset, search, target and notes while retaining currency and asset class. A create with an unknown acknowledgement is read back and invalidates the list without automatically repeating POST. macOS build, VoiceOver, keyboard and Vision Demo verification remain pending.

Fields:

- Search step (only when no asset is selected): `addWatchlist.searchLabel` "Search for a stock, ETF, or crypto", text input, placeholder `addWatchlist.searchPlaceholder` "Search by name or symbol…"; searches after 2 characters (`:97`, `:226`). Loading spinner, then result rows (`SymbolSearchResultItem`, button mode).
- Selected asset summary: name, symbol badge, and `addWatchlist.currentPrice` "Current price: {price}" when a live quote exists (`:263`, `:290`).
- `addWatchlist.assetClass` "Asset class": select with `addWatchlist.stock` "Stock", `.etf` "ETF", `.crypto` "Crypto", `.metals` "Metals"; auto-detected from the asset type (`:57`, `:304`).
- `addWatchlist.currency` "Currency": select USD, EUR, GBP (default USD or the prefill currency) (`:338`).

## Cross-cutting notes

- **No Electron bridge calls.** None of the files in scope call `window.electronAPI` or `ElectronBridge`. Behaviour that the desktop shell must still honour: external links opened with `target="_blank"` (news articles, Ollama setup guide, web evidence), clipboard write (Chart builder Copy share link, `navigator.clipboard.writeText`), browser downloads via a blob `<a download>` (dossier exports, `apps/frontend/src/pages/research/ResearchDossiersPage.tsx:119`), and a native file picker (investigation document upload).
- **Local-only state that a native app must persist:** Chart builder layout library in browser storage (`LOCAL_STORAGE_KEYS.CHART_BUILDER_LAYOUTS`, v2, 250 KB cap). Life scenarios are server-side in the `life_scenarios` setting. The AI chat model override and tools toggle are page-only state and reset on reload.
- **Polling:** Research home benchmarks and watchlist preview (60 s), Market lookup quote (60 s while online), Markets heat tiles (standard stale time), watchlist quotes (shared cache key `watchlistKeys.quotes`), investigation job (1.2 s while running).
- **Endpoints visible in the client calls:** `apiClient.searchResearch`, `searchMarket`, `getMarketQuotes`, `getMarketChart`, `getInvestmentPriceHistory`, `getResearchChart`, `getResearchScorecard`, `getResearchAnalyst`, `getResearchNews`, `searchMacro`, `getMacroSeries`, `getPortfolioForecast`, `getResearchMappings`, `resolveResearchMappings`, `saveResearchMappings`, `deleteResearchMapping`, `auditResearchMappings`, `getWatchlist`, `createWatchlistItem`, `updateWatchlistItem`, `deleteWatchlistItem`, `getSetting` / `saveSetting` (`life_scenarios`), `/api/research-dossiers` (list, get, create, update, delete, versions, restore, export one/all), `listResearchDocuments`, `uploadResearchDocument`, `deleteResearchDocument`, `previewAiDisclosure`, `createAiDisclosureGrant`, `revokeAiDisclosureGrant`, `listAiDisclosureRecords`, `listAiDisclosureGrants`, `deleteAiDisclosureRecords`, `createInvestigation`, `getInvestigation`, `cancelInvestigation`, `resumeInvestigation`, `deleteInvestigation`, and the AI chat hooks in `apps/frontend/src/hooks/useAIChat.ts` (conversations list/create/rename/delete, conversation detail, stream send/cancel, Ollama status and models).
- **Background streaming:** chat streams live in a module-level store, so they continue while the user navigates away; the rail dot and the auto-select on return depend on it (`apps/frontend/src/pages/AIChatPage.tsx:88`, `:92`). A defensive sweep clears a stale streaming entry when a persisted assistant message arrives (`:109`).
- **Unavailable vs empty:** every research data surface distinguishes "provider unavailable" (`ResearchUnavailableNote` or unavailable badge) from "no data" text. A native screen must keep both states.
- **Number and date formats:** amounts, ratios and chart ticks use the app number-format locale and date format settings, not the system locale.
